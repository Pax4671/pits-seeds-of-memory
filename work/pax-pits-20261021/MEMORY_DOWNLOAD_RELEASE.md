## 使い方と変更

AI画面の「Pitsを育てる・記憶を見る」で、名前・話し方・好きなこと・目標を保存できます。「覚えて：私は写真が好きです」と会話で明示するか、記憶フォームから、利用者ごとに20件・各240文字まで保存。訂正・削除・本人エクスポート・アカウント削除・管理者バックアップに対応。返答生成時に性格と最大6件の関連記憶を渡します。モデル自体の追加学習ではありません。

ACADEMYで学んだ内容は利用者が学習メモとして保存し、KATACHIのHTTPS出典を添付できます。講座全文の自動読込み・自動学習を実装したという意味ではありません。

モデル取得を32MiB区画で保存。中断・不完全な応答は区画を完成扱いせず、同じモデル・バックエンドで再開すると完成区画を再利用。Background Fetch対応ブラウザではページを閉じてもOSの取得処理とService Workerの保存処理を利用できます。非対応の場合は画面内取得と再開に切替え、対応状況を表示します。全ブラウザ・OS強制終了・ストレージ削除への継続保証はありません。

Alibaba/Qwen3、標準1.7B/軽量0.6B、容量、初回所要時間、CPU/GPU、ライセンス、保存と学習の違い、品質・端末制約を画面の注釈に追加しました。
